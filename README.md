## Integritetspolicy

**Senast uppdaterad: 4 november 2026**

Den här webbplatsen drivs av **[GitHub Pages]** på domänen **designochkod.se**.

### Uppgifter som webbplatsen hanterar

Inga cookies, analysverktyg, spårningspixlar eller annonseringsteknik används på webbplatsen, inte heller samlas, sparas eller på annat sätt säljes besöksdata på något vis. Webbplatsen har inte någon inloggning, registrering eller några formulär. Det enda som finns är länkar som erbjuder besökaren att starta ett Facetime samtal, skicka ett iMessage samt länk för att skicka ett mejl.

### GitHub och tekniska loggar

GitHub uppger att besökares IP-adresser loggas och lagras av säkerhetsskäl när en webbplats som använder GitHub Pages besöks. Den hanteringen utförs av GitHub, inte av webbplatsen. Läs mer i [GitHubs information om GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) och [GitHubs integritetspolicy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

### Kontakt

Om du kontaktar mig via e-post behandlar jag de uppgifter du själv lämnar, exempelvis din e-postadress och meddelandets innehåll, för att kunna svara. Jag sparar inte uppgifterna lokalt på någon enhet om så inte behövs av rättsliga skäl varav du blir informerad om så sker. All e-post raderas efter 72 timmar och hur den data ditt meddeande innehöll samt hur servern hanterar data, även efter radering, vänligen läs protons villkor. Har du frågor om detta, vänligen kontakta mig här: **[designochkod.se@proton.me]**

### Dina rättigheter

Dataskyddsregler kan ge dig rätt att begära information om, rättelse av eller radering av personuppgifter som jag själv behandlar. Kontakta mig på e-postadressen ovan om du vill göra en sådan begäran. GitHubs egen behandling av uppgifter omfattas av GitHubs integritetspolicy.

### Ändringar

Om webbplatsen börjar använda exempelvis formulär, cookies eller analysverktyg uppdaterar jag den här policyn så att den beskriver den nya hanteringen.
